## Materias donde se usa
- **Laboratorio de Automatización**, con el Mtro. Agustín Cortés Coss. El proyecto se entrega como un
  **Informe Técnico por niveles TRL**: un entregable por nivel ([[entregables-trl]], [[trayectoria-trl]]).
- La materia de teoría (Automatización y Control de Sistemas Dinámicos) usa Sigma como ejemplo para modelar
  sistemas de control; de ahí sale la clasificación de [[sigma-como-sistema-de-control]].

## Qué significa para el código
- Cada nivel TRL tiene que **demostrar lo que el anterior afirmó**. Lo que no se prueba se declara fuera de
  alcance, con la razón ([[niveles-trl]]).
- El proyecto todavía no opera con datos reales. Las pruebas usan datos sintéticos
  ([[arnes-ambiente-relevante]]).
- El idioma del código, los mensajes y la documentación es **español**, con acentos correctos.
